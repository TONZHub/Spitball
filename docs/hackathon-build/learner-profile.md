## Build Preferences

- Preferred pace: Fast, practical, and prototype-oriented.
- Likely support needs: Clear module boundaries, complete replacement files where useful, concrete verification checkpoints, and protection against integration sprawl.
- Notes for downstream commands: Preserve the public-README-only privacy boundary. Spitball should ignore forks, archived repositories, empty repositories, and repositories without README content.
