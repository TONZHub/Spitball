# Spitball

Spitball turns the public README files across a builder's GitHub portfolio into three evidence-grounded hackathon ideas.

## Local setup

1. Install Node.js 24.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` and add the required server-side credentials.
4. Run `npm run dev`.

Planning documents live in `docs/hackathon-build/`.
